## 🎯 Objetivo
Este repositório contém meus estudos diários em Go. O objetivo final é dominar a linguagem para construir ferramentas de infraestrutura, CLI e automação de sistemas (AIOps/DevOps).

---

## 🗺️ Roadmap de Aprendizado

- [x] **Fundamentos**: Variáveis, tipos, loops e condicionais.
- [x] **Estruturas de Dados**: Structs, Slices, Maps.
- [x] **Ponteiros e Métodos**: Receivers e manipulação de memória.
- [ ] **Concorrência**: Goroutines e Channels.
- [ ] **Interface & Erros**: Design de código limpo e tratamento de exceções.
- [ ] **DevOps Tooling**: Criação de CLIs e integração com Docker/Kubernetes API.
